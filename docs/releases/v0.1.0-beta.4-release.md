# Packsmith 0.1.0-beta.4 — revision 3

The beta 4 downloads have been refreshed. The app identifies itself as `0.1.0-beta.4-r3`.

- Files named entirely with whitespace now show as “Whitespace-only name · #ID” in the list and accessible entry text.
- Details and tooltips retain the exact escaped original names. Search accepts both the friendly label and the original; selection and extraction still use real engine entry IDs.

This includes revision 2's layout improvements:

- The file list gets most of the window. Job results stay hidden until there's a result, then show a compact summary with expandable details.
- Open output folder stays available in the compact result. Full diagnostics, mapping and copy controls are available under Show details.
- Removed the extra Packsmith logo/name row above the archive title.

This also includes revision 1's extraction improvements:

- Readable Windows filenames and visible `.rsrc` AppleDouble files are now the default for legacy extraction.
- Resource-only files no longer get empty data placeholders in `.rsrc` mode. Original names and folder Finder metadata remain in the mapping report.
- Available folder modification dates are restored. Archive > Legacy extraction options keeps the earlier escaped-name/`._` preservation mode available.
- `hax-13.hqx` produces 44 items instead of 84 in its main folder, with matching data/resource-fork and file Finder-metadata contents.

The original `v0.1.0-beta.4` tag remains at its publication commit. These refreshed assets come from the newer commit identified by `release-manifest.json`. For matching sources, use the attached source-materials ZIP or that exact commit; GitHub's automatic source downloads still follow the original tag.

This release adds more classic archive coverage and makes the Windows app easier to use.

- Open Compact Pro, LhA and Amiga LZX archives through the existing legacy worker.
- Better method and wrapper details, clearer unsupported-codec errors, and shared Compact Pro fork checksum verification.
- Open archives from the command line, by dropping a file, or from Recent Archives. History is off by default and stores paths only.
- Menus and keyboard access, readable Classic Mac name mapping, expandable results, and improved accessibility text and announcements.
- More known-byte StuffIt, encoding and nested-wrapper tests, plus manifest-driven qualification.

Download the Windows x64 ZIP, extract the whole folder, and run `Packsmith.exe`. It is portable and unsigned. The source-materials ZIP contains the corresponding sources and legacy relink materials. `SHA256SUMS.txt` covers both ZIPs and the release manifest.

The Windows ZIP, corresponding source/relink ZIP, manifest and checksums are replaced together. The release remains Latest, with draft and prerelease disabled.

The refresh passed worker/legacy/Classic export/output-option tests, native model/controller/UI checks, eight GUI/recovery scenarios, branding and relinking checks. Layout checks cover keyboard expansion/collapse and forced Qt scaling at 100%, 150% and 200%, plus enlarged text with a contrasting palette. Filename-label checks cover search, sorting, duplicate entries, exact names in Details and extraction identity. Package integrity and corresponding sources are verified. Historical beta 4 qualification retains its 22-archive corpus and 18-case evidence; this refresh does not claim new classic-format or emulator qualification. See the [extraction update evidence](https://github.com/iSynic/Packsmith/blob/main/assessment/reports/extraction-options.md), [layout check receipts](https://github.com/iSynic/Packsmith/tree/main/assessment/evidence/compact-layout) and [filename-label check receipts](https://github.com/iSynic/Packsmith/tree/main/assessment/evidence/whitespace-labels) for the regressions and measurements.

Format coverage applies to tested subsets. StuffIt X and additional compression/header variants remain unverified. Full spoken Narrator workflows, actual Windows contrast/theme settings and fresh-machine source builds are unfinished. The clean-Windows application pass is user-reported. Expander 7.0.3 investigation is deferred; its cause is undetermined.

See the [support matrix and qualification limits](https://github.com/iSynic/Packsmith/blob/v0.1.0-beta.4/assessment/reports/packsmith-beta4.md). Private archives, extracted files, disk images, ROMs and proprietary tools are excluded from the assets.
