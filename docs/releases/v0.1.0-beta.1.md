# Packsmith 0.1.0-beta.1

The first Windows x64 beta of Packsmith, a native desktop archive manager with classic Macintosh archive support.

## Download and run

Download **Packsmith-0.1.0-beta.1-windows-x64.zip**, extract the entire folder, then run `Packsmith.exe`. Keep the workers and DLLs together. This is an unsigned portable beta; Windows may display a SmartScreen warning. No installer or administrator access is required.

## Included

- ZIP and 7z listing, selected extraction, testing, creation, and add/replace/rename/remove operations. Verified replacement archives retain a backup of the original.
- Read-only StuffIt (`.sit`) and BinHex (`.hqx`) extraction, including supported nested StuffIt wrappers and tested MacBinary (`.bin`) wrappers.
- Mac resource forks and FinderInfo exported as AppleDouble `._` sidecars. Keep these beside their data files, even when the data file is empty.
- Duplicate/case-colliding names preserved, numeric entry selection, original filename/fork hashes in the output mapping, cancellation and interrupted-worker recovery.
- Packsmith icons, Windows beta version metadata, visible control characters in filenames, and explicit extraction-failure dialogs.
- A fix for false checksum failures on valid BinHex-wrapped StuffIt archives, reproduced with `hax-13.hqx` and generated regression fixtures. Real checksum failures still prevent export.

## Validation and limits

18 mainstream worker tests, 12 legacy behavior tests and eight native GUI checks passed with developer PATH entries removed. Embedded icons/version metadata and recovery from the previous Unarchiver data directory passed. The supplied legacy materials rebuilt a helper that passed fork payload checks; a modified helper also ran successfully.

This remains an experimental Windows x64 beta. Fresh Windows VM installation, accessibility, true disk-full/power-loss faults and broader metadata preservation are not qualified. TAR creation, installers, shell integration and native macOS/Linux builds are pending. StuffIt X and broader legacy codec/encoding variants have no acceptance corpus yet. Links are rejected; ACLs, ownership, creation dates and directory timestamps are not preserved. Classic Mac timestamps may reflect the current local UTC offset.

Packsmith-authored code retains LGPL-2.1-or-later; third-party notices accompany the Windows download. **Packsmith-0.1.0-beta.1-source-materials.zip** provides the exact library source packages, patches, build recipes and legacy relinking materials. **release-manifest.json** records the source commit and asset hashes; **SHA256SUMS.txt** provides download checksums.
