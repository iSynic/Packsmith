# Packsmith 0.1.0-beta.3 candidate

Unpublished, unsigned portable Windows x64 candidate. Extract the full Windows ZIP and run `Packsmith.exe`.

- Use **Classic Mac → Export for Classic Mac…** (Ctrl+M), or Export All (Ctrl+Shift+M).
- Review strict naming or explicitly approve mapped names. Output is a verified ZIP with MacBinary II files, restoration instructions and a preservation report.
- Restore with tested **StuffIt Expander 5.5** on System 7.6 or Mac OS 9. Expand remaining `.bin` files in place.
- Preserve both forks, type/creator, portable Finder flags and available raw dates. Missing dates remain unknown; full available FinderInfo stays in the report.
- Review committed output, checksum limits, mappings and recovery paths in the result panel.

Independent comparisons passed 297 files per system, including four real archives. System 7.6 Expander may change reserved resource-header bytes while preserving resource records; original fork bytes remain exact inside the ZIP. Expander 7.0.3 remains unqualified after emulator crashes. Directory metadata, comments, every FinderInfo byte and application compatibility are not promised.

Matching source/relink materials and SHA-256 checksums accompany the candidate. Earlier beta artifacts are preserved. See the [support matrix and handoff](../../assessment/reports/packsmith-beta3.md) for evidence and unverified certification checks.
