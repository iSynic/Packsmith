# Packsmith 0.1.0-beta.2 candidate

Unpublished, unsigned portable Windows x64 candidate. Extract the full Windows ZIP and run `Packsmith.exe`. Keep the data files and AppleDouble sidecars together when moving classic Mac output.

- Browse folders with breadcrumbs, Back/Up and keyboard navigation. Search the whole archive with locations, then return to the prior folder.
- Extract selected entries or the current folder. Use Extract All for the whole archive. Empty selections in search cannot accidentally export everything.
- Inspect data/resource forks, original components, filename encoding, Finder metadata and interpreted timestamps.
- Review durable extraction results, checksum limits, name mappings and recovery information. Success is confirmed after worker exit; copied diagnostics exclude passwords.
- Preserve duplicate directory records and handle transient Windows commit locks with a bounded, cancellable retry.
- Expanded generated/native regression coverage and a private real `.sit`/`.hqx`/MacBinary corpus. Private payloads are excluded from the assets.

The candidate includes matching corresponding-source/relink materials, a snapshot manifest and SHA-256 checksums. Engines and toolchains remain pinned. See the [current handoff and support matrix](../../assessment/reports/packsmith-beta2.md) for receipts and boundaries. Original Mac extraction fidelity, StuffIt X, other script encodings, clean Windows VM qualification and accessibility certification remain unverified. Classic timestamp interpretation and unsupported metadata limitations remain unchanged.
